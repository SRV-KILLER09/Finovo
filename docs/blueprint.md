# **App Name**: EchoPay: Student Finance

## Core Features:

- Login/Registration: Secure user authentication and authorization system for personalized access. Registration includes connecting bank accounts and UPI.
- Dashboard: Intuitive dashboard providing an overview of financial status.
- Advanced Budgeting & Cash Flow: Scenario-based budgeting, cash flow prediction and shared budgeting functionalities.
- Income & Funding Management: Track multiple income sources, auto-import transactions, and access a tax calculator for student jobs or stipends.
- AI-Based Scholarship Finder: Recommends opportunities based on user profiles using an AI tool.
- AI-Powered Financial Health Reports: Generates weekly/monthly financial health reports, providing insights into spending and saving habits, using an AI tool.
- Gamification & Rewards: Points/badges for good financial habits, leaderboards for savings challenges and redeemable student discounts/offers from partnered brands.

## Style Guidelines:

- Primary color: Deep blue (#293462) to inspire trust and financial stability.
- Background color: Light gray (#E8E8E8) provides a clean and modern aesthetic.
- Accent color: Teal (#00A36C) to highlight important actions and information.
- Body and headline font: 'Inter' sans-serif, for a modern, machined, objective look.
- Minimalist icons with a consistent line weight for a clean interface.
- Grid-based layout for responsiveness across devices. Prioritize key information above the fold on dashboard.
- Subtle transitions and animations to provide feedback on user interactions, without being distracting.
